# 🔴🟢 Pokédex Web

Este projeto é uma **Pokédex interativa** que permite pesquisar e visualizar informações sobre os Pokémon de forma dinâmica. Possui duas páginas principais: uma que simula uma Pokédex clássica e outra que lista todos os Pokémon disponíveis, permitindo uma busca progressiva conforme o usuário digita.

## ✨ Funcionalidades

- 🔍 **Pesquisa interativa** de Pokémon pelo nome.
- 📜 **Lista completa** de todos os Pokémon disponíveis.
- 🆎 **Busca dinâmica**: conforme o usuário digita, os Pokémon que contêm as letras inseridas aparecem automaticamente.
